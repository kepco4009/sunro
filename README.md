# 순로앱 시제품 (W1 시험용)

가짜 주소 12곳으로 동작하는 시험 화면입니다. 업무 자료는 들어 있지 않습니다.

- index.html : 계산 화면 (주소 입력 → 순서 계산 → QR·링크)
- sheet.html : 휴대폰 순서표 (주소를 누르면 네이버 길안내)
- core.js : 순서 계산 모듈 / qr.js : QR 생성(MIT, Kazuhiko Arase 기반)
- data/addr_sample.json : 시험용 가짜 주소·좌표
- data/t5.bin, t10.bin, t20.bin : 큰 파일 받기 시험용 (무작위 값, 별도 압축 파일로 제공)

주의: 이 저장소는 공개입니다. 방문 주소·메모 등 업무 자료를 올리지 마십시오.
