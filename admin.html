순로앱 관리자 화면

지사(부서)마다 번호와 기본 설정을 넣고 [앱용 설정 파일 만들기]를 누르면 dept.json이 내려받아집니다. 이 파일을 GitHub 저장소 맨 위에 올리면 바로 적용됩니다.
• 번호는 숫자만 씁니다(본부 번호 + 코스트센터, 예: 14009). 자릿수 제한은 없습니다.
• dept.json 안에서 번호와 설정은 잠겨 있어 글자로 보이지 않습니다. 대신 원래 번호는 파일에서 다시 꺼낼 수 없으므로 [원본 목록 저장]으로 받은 파일을 관리자가 따로 보관하세요. 원본 목록 파일은 GitHub에 올리지 마십시오.
• 공개돼도 상관없는 정보(지사 주소 등)만 넣습니다. 직원 자택 주소는 넣지 않습니다.
